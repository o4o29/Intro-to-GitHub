# Intro-to-GitHub

This repository was created as part of Introductory Activity 3 for Git and GitHub in Elective 4: DevOps. It contains activities and exercises that demonstrate the basic concepts and usage of Git and GitHub.

## Purpose

The purpose of this repository is to practice basic Git and GitHub operations, such as creating repositories, adding files, committing changes, and pushing changes to GitHub.

## Contents

- `README.md` - Contains information about the repository.
- `about-me.txt` - Contains a short introduction.
- `sample-code.java` - Contains a simple Java program.
- `git-commands.txt` - Contains basic Git commands used in the activity.
